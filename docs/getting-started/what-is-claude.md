# What Claude Pro includes

What your Claude Pro account gives you, and when to use each part. Anthropic changes the details often; the [official plan comparison](https://claude.com/pricing) is the reference.

!!! info "Chat and Cowork are now one Claude"
    Since September 2026, what used to be a separate mode called **Cowork** (longer, multi-step tasks) is part of every conversation. You just describe what you need, and Claude either answers or works on the task for a while and hands you finished files. The change is rolling out gradually: if your message box still shows separate **Chat** and **Cowork** options, you don't have it yet. See [Longer tasks and scheduling](../using-claude/tasks.md).

## Where you can use it

One account, the same chats everywhere:

| Where | Good for |
|---|---|
| **Web**, at [claude.ai](https://claude.ai) | Almost everything. Nothing to install. |
| **Desktop app** (macOS, Windows), from [claude.ai/download](https://claude.ai/download) | Same as web, plus access to folders on your computer, a built-in browser and the **Code** tab. |
| **Mobile app** (iOS, Android) | Quick questions, voice mode, photos of a blackboard, and following or steering long tasks you started at your desk. |
| **Claude Code** (terminal, VS Code, JetBrains, desktop app, web) | Working on your code and analysis scripts. See [Claude Code](../using-claude/claude-code.md). |
| **Claude in Chrome** | Claude reads and acts on web pages in your browser. See [Claude in Chrome](../using-claude/chrome.md). |
| **Claude for Microsoft 365** | Add-ins for Excel, Word and PowerPoint (Outlook in beta). See [Email, calendar and documents](../using-claude/email-calendar.md). |
| **Claude Science** (beta) | A desktop workbench for running analyses with code, data and compute. See [Claude Science](../using-claude/science.md). |

## Models

Pick the model in the menu below the message box.

- **Sonnet** is the everyday model. Fast and strong; use it for almost everything.
- **Opus** is more capable. Use it for hard reasoning, long derivations or tricky code. It uses your allowance faster.
- **Haiku** is the small, fast model, for quick simple tasks.
- **Fable** is Anthropic's most advanced model. On Pro it is **not covered by your plan's usage**: it is paid separately with usage credits from the first message. Only pick it if you mean to pay for it.
- **Effort**, in the same menu, sets how long Claude reasons before answering (older versions call it *Extended thinking*). The default suits most work; raise it for problems where you would want a colleague to think before replying, lower it for quick answers that use less of your allowance.

## Usage limits {#usage-limits}

Pro is not unlimited.

- Usage is counted over a **five-hour session**. When you reach the limit, Claude shows when it resets.
- There is also a **weekly limit** on top of the session limit.
- Chat, longer tasks, Claude Code and the desktop app all share the same allowance.
- Long conversations, large files, long multi-step tasks, Opus and a high effort setting use the allowance faster.
- Check where you stand in **Settings → Usage**.
- **Usage credits**: you can switch them on so that work continues, at a cost, when you hit the limit. Leave them off if you don't want to pay more than the subscription. Fable always uses them.

To make it last: start a new chat for each new topic, put files you reuse in a [Project](../using-claude/projects.md) instead of re-uploading them, and keep Opus and high effort for the problems that need them.

If you regularly hit the limits, the **Max** plan offers 5× or 20× more usage at a higher price.

## What Pro does not include

- **No contract between UB and Anthropic.** Pro is a personal (consumer) plan. Your data is handled under Anthropic's consumer terms, not an institutional agreement. Read [Data and privacy](data-and-privacy.md).
- **No API access.** Using Claude from your own programs through the API is billed separately at [platform.claude.com](https://platform.claude.com). (Max and Team plans now include some monthly API credits; Pro does not.)
- **No shared admin.** Projects and chats are yours; you cannot share a Project with colleagues. There is no ICCUB-wide workspace. A group [Team plan](get-claude.md) adds sharing.
