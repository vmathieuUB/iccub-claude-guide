# What Claude Pro includes

What your Claude Pro account gives you, and when to use each part. Anthropic changes the details from time to time; the [official plan comparison](https://claude.com/pricing) is the reference.

## Where you can use it

One account, the same chats everywhere:

| Where | Good for |
|---|---|
| **Web**, at [claude.ai](https://claude.ai) | Everything. Nothing to install. |
| **Desktop app** (macOS, Windows), from [claude.ai/download](https://claude.ai/download) | Same as web, in its own window, with access to local tools, plus the **Code** tab for [Claude Code](../using-claude/claude-code.md). |
| **Mobile app** (iOS, Android) | Quick questions, voice mode, photos of a blackboard or a page. |
| **Claude Code** (**Code** tab of the desktop app, VS Code, JetBrains, terminal) | Working on your code and analysis scripts. See [Claude Code](../using-claude/claude-code.md). |
| **Claude in Chrome** and **Microsoft 365** integrations | Using Claude inside your browser and Office apps. |

## Models

Pick the model in the menu below the message box.

- **Sonnet** is the default. Fast and strong; use it for almost everything.
- **Opus** is the most capable model. Use it for hard reasoning, long derivations or tricky code. It uses your allowance faster.
- **Extended thinking**, in the same menu, lets Claude reason longer before answering. Turn it on for problems where you would want a colleague to think before replying.

## Usage limits

Pro is not unlimited.

- Usage is counted over a **rolling five-hour session**. When you reach the limit, Claude shows when it resets.
- There is also a **weekly limit** on top of the session limit.
- Chat and Claude Code share the same allowance.
- Long conversations, large files, Opus and extended thinking use the allowance faster.

To make it last: start a new chat for each new topic, put files you reuse in a [Project](../using-claude/projects.md) instead of re-uploading them, and keep Opus for the problems that need it.

If you regularly hit the limits, the **Max** plan offers 5× or 20× more usage at a higher price.

## What Pro does not include

- **No contract between UB and Anthropic.** Pro is a personal (consumer) plan. Your data is handled under Anthropic's consumer terms, not an institutional agreement. Read [Data and privacy](data-and-privacy.md).
- **No API access.** Using Claude from your own programs through the API is billed separately at [console.anthropic.com](https://console.anthropic.com).
- **No shared admin.** Projects and chats are yours; there is no ICCUB-wide workspace.
