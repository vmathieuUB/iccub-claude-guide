# Research examples

- [Write a conference proceeding](conference-proceeding.md): slides, analysis note and the conference template in one folder, one long prompt, and a finished proceeding in about half an hour.
- [Clean up and test an analysis pipeline in VS Code](analysis-code-vscode.md): freeze current results, refactor in small steps, add tests and documentation before a handover.
- [Run a local LLM on your laptop](local-llm-laptop.md): install Ollama, pick a model that fits your RAM, and use it from the terminal and VS Code.
- [Share a local LLM over the network](local-llm-remote-access.md): serve models from one Mac to another on the same network, including a working VS Code coding agent.
