# Examples

Short, concrete write-ups of tasks done with Claude, in four areas. Every example follows the same [template](../contribute/example-template.md): goal, what was done, result, and what to watch for.

!!! info "Help us replace the illustrative examples"
    Examples marked *Illustrative* were written by the site editors to show what is possible. We want real ICCUB experiences instead. If you try one, or have done something similar, [send your version](../contribute/index.md).
