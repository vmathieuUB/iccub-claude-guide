# How to use Claude

One page per feature. Each page says what the feature is, when to use it, and how, with ICCUB examples.

| Page | Read it when you want to… |
|---|---|
| [Chat and prompting](prompting.md) | get better answers from an ordinary chat |
| [Uploading files](files.md) | work with papers, data, plots or code |
| [Projects](projects.md) | keep files and instructions together for a course, a paper or a proposal |
| [Artifacts](artifacts.md) | get a document, a figure, a quiz or a small app you can edit and share |
| [Web search and Research](research.md) | have Claude look things up and cite its sources |
| [Connectors](connectors.md) | let Claude read your Google Drive, email, calendar or GitHub |
| [Claude Code](claude-code.md) | have Claude read, edit and run code in your own projects |

If you are new, start with [Chat and prompting](prompting.md). Everything else builds on it.
