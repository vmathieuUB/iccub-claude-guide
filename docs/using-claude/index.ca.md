# Com utilitzar Claude

Una pàgina per funció. Cada pàgina explica què és la funció, quan utilitzar-la i com, amb exemples de l'ICCUB.

| Pàgina | Llegeix-la quan vulguis… |
|---|---|
| [Xat i prompts](prompting.md) | obtenir millors respostes en un xat normal |
| [Pujar fitxers](files.md) | treballar amb articles, dades, gràfics o codi |
| [Projects](projects.md) | tenir junts els fitxers i les instruccions d'una assignatura, un article o una proposta |
| [Artifacts](artifacts.md) | obtenir un document, una presentació, un disseny, un qüestionari o una petita aplicació que puguis editar, exportar i compartir |
| [Tasques llargues i programades](tasks.md) | encarregar a Claude una tasca sencera, deixar-lo treballar amb fitxers del teu ordinador, repetir-la periòdicament o ensenyar-li amb skills |
| [Cerca web i Research](research.md) | que Claude busqui informació i en citi les fonts |
| [Connectors](connectors.md) | deixar que Claude llegeixi el teu Google Drive, correu electrònic, calendari o GitHub |
| [Correu electrònic, calendari i documents](email-calendar.md) | que Claude t'ajudi amb la safata d'entrada, les reunions i la gestió |
| [Claude in Chrome](chrome.md) | que Claude llegeixi pàgines web i hi actuï des del teu navegador |
| [Claude Code](claude-code.md) | que Claude llegeixi, editi i executi codi als teus propis projectes |
| [Claude a VS Code](vs-code.md) | utilitzar Claude dins de VS Code per a codi, LaTeX i notes |
| [Claude Science](science.md) | fer anàlisis de recerca amb traçabilitat i els teus propis recursos de càlcul (beta) |

Si hi ets nou, comença per [Xat i prompts](prompting.md). Tota la resta s'hi basa.
