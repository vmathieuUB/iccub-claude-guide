# Contribueix

Tothom a l'ICCUB pot afegir un exemple o millorar una pàgina. Pot ser breu, i els fracassos són tan útils com els èxits.

## Envia un exemple

1. **Descarrega la plantilla**: [iccub-example-template.md](../assets/example-template.txt){: download="my-example.md" .md-button } o copia-la des de la pàgina [Plantilla d'exemple](example-template.md).
2. **Omple-la** amb qualsevol editor de text (VS Code, TextEdit, Bloc de notes…). Substitueix el text entre angles. N'hi ha prou amb deu o quinze minuts.
3. **Envia-la per correu** a **[vmathieu@ub.edu](mailto:vmathieu@ub.edu?subject=ICCUB%20Claude%20Guide%20example)** amb el fitxer adjunt. Afegeix-hi captures de pantalla o altres fitxers si són útils.

Els editors la publicaran al web i t'enviaran l'enllaç.

!!! tip "No saps ben bé com escriure-ho?"
    Demana-ho a Claude: puja la plantilla, descriu en unes quantes frases què vas fer i demana *"Omple aquesta plantilla a partir de la meva descripció. Mantén les meves paraules sempre que puguis i pregunta'm tot el que hi falti."* Després revisa el resultat abans d'enviar-lo.

## Millora una pàgina

Has vist un error, un nom de menú desactualitzat o alguna cosa que hi falta? Escriu a [vmathieu@ub.edu](mailto:vmathieu@ub.edu?subject=ICCUB%20Claude%20Guide%20correction) amb l'enllaç de la pàgina i què cal canviar.

Si fas servir GitHub, també pots obrir una pull request al [repositori del web](https://github.com/vmathieuUB/iccub-claude-guide): les pàgines són fitxers Markdown a `docs/`.

## Abans d'enviar-ho

- Elimina qualsevol cosa confidencial: resultats no publicats, dades d'estudiants, contrasenyes, adreces IP privades. Consulta [Dades i privadesa](../getting-started/data-and-privacy.md).
- Indica si vols que hi consti el teu nom o si prefereixes mantenir l'anonimat.
