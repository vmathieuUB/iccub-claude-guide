# Contribute

Anyone at ICCUB can add an example or improve a page.

## Send an example

1. Copy the [example template](example-template.md).
2. Fill it in. Ten to fifteen minutes is enough; short is fine, and failures are as useful as successes.
3. Send it in one of two ways:
    - **With GitHub**: open a pull request adding your page under `docs/examples/<area>/`.
    - **Without GitHub**: use the submission form (link to come) and the editors will publish it.

## Before you send

- Remove anything confidential: unpublished results, student data, passwords, private IP addresses.
- Say whether you want your name on it or prefer to stay anonymous.
