# Contribute

Anyone at ICCUB can add an example or improve a page. Short is fine, and failures are as useful as successes.

## Send an example

1. **Download the template**: [iccub-example-template.md](../assets/example-template.txt){: download="my-example.md" .md-button } or copy it from the [example template](example-template.md) page.
2. **Fill it in** with any text editor (VS Code, TextEdit, Notepad…). Replace the text in angle brackets. Ten to fifteen minutes is enough.
3. **Email it** to **[vmathieu@ub.edu](mailto:vmathieu@ub.edu?subject=ICCUB%20Claude%20Guide%20example)** with the file attached. Add screenshots or other files if they help.

The editors will put it on the site and send you the link.

!!! tip "Not sure how to write it?"
    Ask Claude: upload the template, describe what you did in a few sentences, and ask *"Fill in this template from my description. Keep my wording where you can and ask me about anything missing."* Then check the result before you send it.

## Improve a page

Spotted a mistake, an outdated menu name, or something missing? Email [vmathieu@ub.edu](mailto:vmathieu@ub.edu?subject=ICCUB%20Claude%20Guide%20correction) with the page link and what to change.

If you use GitHub, you can also open a pull request on the [site repository](https://github.com/vmathieuUB/iccub-claude-guide): pages are Markdown files in `docs/`.

## Before you send

- Remove anything confidential: unpublished results, student data, passwords, private IP addresses. See [Data and privacy](../getting-started/data-and-privacy.md).
- Say whether you want your name on it or prefer to stay anonymous.
