    Projects¶

    Un Project (projecte) és una carpeta per a xats que comparteixen els mateixos fitxers i instruccions. Fes-ne servir un per assignatura, article, proposta o tasca llarga.

    Per què fer-ne servir un¶

    • Els fitxers, una sola vegada: puja el pla docent, l'esborrany o la descripció de les dades una vegada; tots els xats del Project els poden fer servir.
    • Les instruccions, una sola vegada: explica a Claude el públic, l'estil i les normes una vegada, no a cada xat.
    • Historial endreçat: tots els xats sobre un mateix tema en un sol lloc.

    Amb Pro pots tenir tants Projects com vulguis. Els Projects grans es gestionen automàticament: Claude cerca als fitxers del Project i n'agafa les parts rellevants.

    Crea'n un¶

    1. Fes clic a Projects a la barra lateral esquerra i després a New project.
    2. Posa-li un nom i, si vols, una descripció.
    3. Afegeix fitxers a Project knowledge: PDF, text, codi, notes.
    4. Escriu les Project instructions (mira més avall).
    5. Comença un xat dins del Project.

    Escriu bones instruccions¶

    Les instruccions s'afegeixen a cada xat del Project. Fes-les breus i concretes.

    Aquest Project és per a l'assignatura "Astrofísica Extragalàctica" (4t curs,
Grau en Física, UB). Els estudiants saben física de grau i Python bàsic.
- Escriu el material de l'assignatura en català si no et demano el contrari.
- Fes servir la notació dels apunts adjunts.
- Exercicis: dona un enunciat i després una solució completa en una secció a part.
- No inventis mai referències. Si cites alguna cosa, digues si estàs segur que existeix.

    Idees per a l'ICCUB¶

    Project Què hi has de posar
    Una assignatura Pla docent, apunts, exàmens anteriors, convencions de notació
    Un article en curs El teu esborrany, les referències clau, les normes d'estil de la col·laboració (si es permet compartir-les)
    Una proposta de finançament El text de la convocatòria, els criteris d'avaluació, el teu CV, propostes anteriors
    El codi del teu grup README, una descripció del pipeline, convencions de programació
    Divulgació El teu públic objectiu, xerrades anteriors, el format de l'espai o l'esdeveniment

    Note

    Amb un pla Pro, els Projects són privats. No pots compartir un Project amb un col·lega; comparteix-ne els fitxers i les instruccions.
